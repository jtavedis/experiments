The new rule

The basic earnings formula is unchanged ($6 per red card you keep, plus $1 per red card in the stack). But now there is a {{ risk_pct }}% risk that everyone loses all earnings for the round, unless the group contributes enough red cards.

  • If the total number of red cards in the stack reaches {{ threshold_n }} or more, the round is completely safe — no risk applies.
  • If the stack falls short of {{ threshold_n }} red cards, a single random number from 1 to 10 is drawn for the whole class. {% if phase == 2 %} If it is 1, 2, 3, or 4 ({{ risk_pct }}% chance), everyone earns $0 this round. {% else %} If it is 1 through 9 ({{ risk_pct }}% chance), everyone earns $0 this round. {% endif %}

Reaching the threshold protects everyone — but each red card you contribute is one you don't keep for yourself. Click Next when ready.
